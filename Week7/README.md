# Week 7 - Advanced React Exercises

This project implements the requested Week 7 tasks:

## 1) Advanced React
- Hooks: `useState`, `useEffect`, `useContext`, `useReducer`, `useMemo`
- Global state management: Context API + reducer store
- Routing: React Router (`Home`, `About`, `Contact`, `GitHub`, `Login`)

## 2) API Integration
- Public API: GitHub Users API (`https://api.github.com/users/{username}`)
- Handles loading, success, and error states with retry

## Exercises Covered
### Multi-Page React App
- Implemented with React Router and shared global state in context

### API Consumption
- Fetches and displays GitHub user data

## Assessment-Style Feature
- Mock authentication form with validation rules
- Updates global store on login/logout
- Persists auth state in local storage as a mock backend behavior

## Run
1. `npm install`
2. `npm run dev`
3. Open the local Vite URL shown in terminal
